# 今日任务重设计 — 设计文档

- **日期**：2026-06-23
- **状态**：待评审
- **子项目**：🅰️ 扩展端重设计(🅱️ 飞书任务机器人单独立项)

## 1. 背景与目标

现有"每天打满清单"的方式给用户造成压力。本次重设计把核心理念从"完成一长串清单"转为"**每天只盯住 1-3 件必做 + 强正反馈**",其余任务沉淀为"可做可不做"的任务池,做了就是锦上添花。

**核心目标:**
- 今日清单永远短(1-3 个必做),从结构上消除"清单越积越长"的压力
- 完成必做有强仪式感的正反馈;超额完成有"更上一层"的奖励
- 把原 To-do List 重新定位为低压力的"任务池"

**范围:** 本文档只覆盖 Chrome 扩展端。飞书任务机器人(自然语言输入 → LLM 提炼 → 写入)是依赖本设计数据格式的独立子项目,后续单独设计。两者通过 Obsidian 文件(`todo.md` 等)作为共享数据层解耦。

## 2. 设计决策汇总

| # | 决策 | 选择 |
|---|------|------|
| D1 | 必做未完成的跨日处理 | 退回任务池,今日每天从 0 开始(永远 1-3 个) |
| D2 | 必做任务来源 | 从任务池"提升" + 可临时新建 |
| D3 | 完成反馈 | 强仪式感:打勾动画 + 彩纸/粒子 + 轻音效 + 大庆祝 |
| D4 | 超额反馈 | 即时金色"超神"庆祝 + 长期 streak/累计看板 |
| D5 | 任务池结构 | 完全保留现有 `todo.md`(分段/优先级/分类),仅改定位 |
| D6 | 今日必做与任务池关系 | 高亮式:今日必做 = 池子里被 `#今日` 标记的项,不搬移 |

## 3. 数据模型与文件格式

### 3.1 任务池 = `todo.md`(唯一任务库)

完全保留现有结构(H2 分段、`[S/A/B/C]` 优先级、`#家庭/#工作/#健康/#学习` 分类、`← [[wikilink]]` 引用)。

### 3.2 今日必做 = 被 `#今日` 标记的池子项(高亮式)

- 设为必做:给该任务行追加 `#今日` tag;退回:移除 tag。**不搬移任务行位置**。
- 临时新建的今日必做:写入 `todo.md`(默认"短期任务"段)+ 打 `#今日`。
- 数量约束:最多 3 个 `#今日`;名额满时 UI 提示。
- 示例:
  ```
  ## 短期任务（7 天内完成）
  - [ ] [S] 写完项目方案初稿 #工作 #今日
  - [ ] 给妈妈打电话 #今日
  - [ ] [A] 思考黄金投资事宜 #家庭
  ```
- **解析要点**:`todo-sync.js` 需把 `#今日` 识别为"今日必做"标志并从展示文本剥离,不能误当分类(现有分类正则只认 家庭/工作/健康/学习,需新增对 `#今日` 的单独处理)。

### 3.3 每日完成日志(喂 streak / 累计看板)

- **主存储**:`chrome.storage.local` 的 `completionHistory`,按日期键:
  ```js
  {
    "2026-06-23": {
      mustDoTotal: 2,        // 当天必做数
      mustDoCompleted: 2,    // 完成的必做数
      overAchieved: ["回复客户邮件", "健身 30 分钟"]  // 超额完成的任务
    }
  }
  ```
- **可读镜像**:每天把快照写入 `1_memory/tasks/YYYYMMDD_Daily_Tasks.md`(Obsidian 可读、飞书机器人将来可读)。`Daily_Tasks.md` 从"今日任务清单"转型为"当天完成日志"。格式:
  ```
  ---
  date: 2026-06-23
  type: daily-log
  ---
  # 2026-06-23 完成日志
  ## 今日必做 (2/2)
  - [x] 写完项目方案初稿
  - [x] 给妈妈打电话
  ## 超额完成 (2)
  - [x] 回复客户邮件
  - [x] 健身 30 分钟
  ```

### 3.4 streak 定义(对齐"减压")

- **主 streak = 连续达成天数**:某天"必做全部完成"即算达成,streak +1。**不要求当天超额**——以免给超额制造压力,违背减压初衷。
- **超额作为累计指标**:本周/本月超额任务数、月度徽章,不影响 streak 是否断裂。
- (可调项:若用户更想要"连续超额"口径,改这里即可。)

## 4. 今日页面

- 顶部:`已完成/总数` 进度 + 常驻一个小 streak 火苗(如"连续 4 天")。
- 1-3 张大必做卡片:大字 + 圆形 checkbox。**今日卡片不显示 S/A/B/C**(就这几个无需排序);分类用一个小色点带过。
- 完成单个必做:打勾动画 + 彩纸/粒子 + 轻音效 + 即时鼓励语。
- 全部必做完成:奖杯庆祝块 + "从任务池捞一个 →"入口。
- 空状态(还没设必做):引导"去任务池挑 1-3 件,或直接新建今天的必做"。

## 5. 任务池页面(原 To-do List 升级)

- 保留现有分段/优先级/分类。
- **定位与文案改为"备选池"**:视觉与措辞弱化"必须感"(不再像欠债清单);完成池子任务的反馈轻量即可。
- 每项新增"设为今日必做 🎯"快捷操作(打 `#今日`);名额(3)满时提示。

## 6. 超额与长期激励

- **超额界定**:必做全部完成后,当天再完成的任意任务(来自池子或临时)= 超额。
- **即时**:金色"超神"庆祝(与绿色"必做达成"区分),列出超额任务。
- **长期看板**:连续达成天数(streak)、本周/本月超额累计、月度徽章。
- **位置**:内嵌在今日页(全部达成后展开 + 常驻小入口),**不新增 tab**。

## 7. 跨日逻辑(改 `background.js`)

- **废弃**现有"午夜把未完成任务全量复制到今天"的 rollover。
- **新逻辑**(午夜定时):
  1. 归档当天完成情况到 `completionHistory` + 写 `YYYYMMDD_Daily_Tasks.md` 快照;
  2. 清除 `todo.md` 中所有 `#今日` 标记(必做自动退回池子);
  3. 新的一天从 0 个必做开始。

## 8. 导航与 UI

- 两个主 tab:**今日** / **任务池**(长期看板内嵌今日页,不占 tab)。
- 沿用现有原生 JS + CSS 架构(零依赖)。

## 9. 反馈实现要点(零依赖)

- 打勾动画:CSS transition/animation。
- 彩纸/粒子:轻量 `<canvas>` 或纯 CSS,不引入第三方库。
- 轻音效:Web Audio API 程序化生成(或内联极小 base64 音频);首次需用户手势解锁 `AudioContext`(完成点击本身即手势)。

## 10. 受影响文件

| 文件 | 改动 |
|------|------|
| `task-manager.js` | 数据模型:`#今日` 标志、完成日志、streak 计算 |
| `todo-sync.js` | 解析/写回 `#今日` tag(与分类区分) |
| `obsidian-sync.js` | `Daily_Tasks.md` 改为完成日志快照写入 |
| `storage.js` | 新增 `completionHistory` 读写 |
| `background.js` | rollover 改为"归档 + 清今日标记 + 重置" |
| `sidepanel.html/.css/.js` | 今日页重构、任务池升级、反馈动画、看板、空状态 |

## 11. 数据兼容与迁移

- 现有 `todo.md`:无破坏性改动,新增 `#今日` tag 即可;未标记的项保持现状。
- 现有 `YYYYMMDD_Daily_Tasks.md`:语义转为完成日志;历史文件保留不动,新逻辑只写当天。
- 首次启用:`completionHistory` 为空,streak 从 0 起算。

## 12. 验收标准

- 今日页任意时刻最多 3 个必做;超出时设为必做被拦截并提示。
- 必做未完成,次日自动退回池子(`#今日` 被清),今日页归零。
- 完成单个必做触发动画/音效/鼓励;全部完成触发庆祝 + 任务池入口。
- 必做全完成后再完成任务,触发金色超额庆祝,并记入 `overAchieved`。
- streak 与本周/本月累计能从 `completionHistory` 正确算出并展示。
- 任务池完整保留现有分段/优先级/分类,数据不丢。
- 跨日归档把当天写入 `completionHistory` 和 `Daily_Tasks.md` 快照。

## 13. 非目标(本期不做)

## 14. 开放 / 可调项

- streak 口径(连续达成 vs 连续超额)。
- `#今日` 标记的具体写法(tag vs emoji),当前定为 `#今日` tag。
- 徽章规则(达到什么条件给什么徽章)留待实现时细化。
